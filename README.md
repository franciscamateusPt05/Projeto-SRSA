## Description
Projeto-SRSA is a project developed entirely in Python. The repository is divided into different delivery phases, specifically "Parte1" and "Meta 2-SRSA", reflecting the structured progress and the various components planned for the system.

## Technologies
- **Main Language:** Python
- **Development Environment:** Configurations compatible with PyCharm / IntelliJ (evidenced by the `.idea` directory)

## Project Structure
```text
Projeto-SRSA/
├── .idea/                  # IDE configuration files
├── Meta 2-SRSA/            # Code and files related to the second project milestone
├── Parte1/                 # Code and files related to the first phase
└── Meta 2-SRSA.zip         # Compressed archive containing the milestone 2 content
```

## Getting Started

Follow these instructions to get a copy of the project up and running on your local machine.

### Prerequisites

Before proceeding, ensure you have the following installed on your system:

- **Python 3.x** (The latest version is recommended)
- **Pip** (Python package installer)

### Installation

Clone the repository to your local machine using the terminal:

```bash
git clone [https://github.com/franciscamateusPt05/Projeto-SRSA.git](https://github.com/franciscamateusPt05/Projeto-SRSA.git)
```

Navigate into the main project directory:

```bash
cd Projeto-SRSA
```

### Running the Application

Since the project is divided into several parts, you must navigate to the specific directory you wish to run.

1. Access the desired phase directory (for example, Parte 1):

```bash
cd Parte1
```

*(Alternatively, navigate to Meta 2: `cd "Meta 2-SRSA"`)*

2. Run the main Python script (replace `main.py` with the correct executable file name located in the folder):

```bash
python main.py
```

*Note: On Linux or macOS systems, you might need to use the `python3` command instead of `python`.*
